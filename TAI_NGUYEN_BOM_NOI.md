## 🎨 **TẠO SPRITES ĐƠN GIẢN (Nếu không tìm được):**

### **Bomb Sprite:**

**Cách 1: Vẽ trong Paint/GIMP:**
```
1. Tạo canvas 64x64px
2. Vẽ hình elip đen (quả bom)
3. Thêm dây cháy màu vàng/đỏ
4. Save as PNG với transparent background
```

**Cách 2: Dùng emoji:**
```
💣 Copy emoji này
Paste vào Word/PowerPoint
Phóng to → Screenshot → Crop
Có bomb sprite ngay!
```

### **Explosion Sprite (Đơn giản):**

**Frame 1:** Vòng tròn nhỏ màu vàng
**Frame 2:** Vòng tròn to hơn màu cam
**Frame 3:** Vòng tròn to nhất màu đỏ
**Frame 4:** Vòng tròn nhỏ lại màu đen (khói)

```
Tạo 4 sprites như trên
→ Animation complete!
```

## 💡 **TIPS:**

### **Sprites:**
1. Chọn style match với game (pixel art)
2. Kích thước 64x64 hoặc 128x128 là đủ
3. Ít nhất 4 frames cho explosion
4. PNG với transparent background

### **Sounds:**
1. Format: MP3 hoặc WAV
2. Duration: 0.5-2 giây
3. Volume: Normalize trước khi import
4. Mono sound để nhẹ hơn

### **License:**
- ✅ CC0 (Public Domain) - Dùng tự do
- ✅ CC BY (Attribution) - Ghi credit
- ❌ Tránh copyrighted content
